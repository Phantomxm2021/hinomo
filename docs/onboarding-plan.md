# Nomo 新用户引导与全局多语言方案

## 目标

Nomo 的核心路径是“场地 → 空间 → 箱子 → 物品”。新用户第一次进入首页时，需要知道下一步做什么，但引导不应占据业务列表或制造一条假的数据记录。本方案把引导放在独立弹窗中，并让桌面端、移动端和跨设备使用保持同一套状态。

支持的界面语言固定为：

- 简体中文（`zh-CN`，默认）
- English（`en-US`）

## 当前实施状态

- 首页内嵌的新手进度卡已下线，不再向空间、箱子或物品列表插入引导条目；
- 首次进入 `/app` 且账号尚未完成基础激活时，显示一次“开始使用 Nomo”引导弹窗；
- 弹窗关闭后不再自动出现，用户可以通过 Dashboard 的“新手指南 / Getting started”入口手动重开；
- 弹窗展示即调用幂等 RPC，将记录写入 `profiles.onboarding_welcome_seen_at`；因此用户关闭后，移动端不会再次自动弹出；
- 进度仍由真实业务数据计算：空间、箱子、第一件物品；
- 所有界面使用全局 `zh-CN / en-US` 字典，不按登录状态分叉；
- 语言优先读取浏览器 `localStorage`（键名 `nomo-locale`），登录后通过 profile 同步到账号，切换语言时更新页面 `lang` 属性；
- 桌面端弹窗居中显示，移动端使用底部抽屉，390px 宽度下保持无横向溢出；
- 用户选择关闭后，后续仅由手动入口打开，不再自动打扰。

## 激活定义与跨设备规则

基础激活包含三个动作：

1. 创建至少一个空间；
2. 创建至少一个箱子；
3. 在任意箱子中记录至少一件物品。

引导进度使用账号范围内的数据，而不是当前选中的场地，避免用户在桌面端和移动端切换场地后看到相互矛盾的步骤。当前业务内容仍按所选场地过滤；只有引导进度使用全账号数据。

`mark_onboarding_welcome_seen()` 是幂等的安全数据库函数：首次调用写入时间戳，重复调用不覆盖原始时间。这样可以在多个设备同时打开页面时保持一致。

## 弹窗交互

弹窗只展示当前需要完成的步骤，同时列出三个步骤的完成状态：

### 没有空间

- 标题：`从一个空间开始` / `Start with a space`
- 说明：空间可以是客厅、卧室、储藏室，也可以是一组货架。
- CTA：`创建第一个空间` / `Create your first space`
- 目标：`/app/spaces?create=1`

### 有空间、没有箱子

- 标题：`创建第一个箱子` / `Create your first box`
- 说明：记录它放在哪里、里面有什么，以后就不用再翻找。
- CTA：`创建第一个箱子` / `Create your first box`
- 目标：`/app/boxes?create=1`

### 有箱子、没有物品

- 标题：`记录箱内物品` / `Record what is inside`
- 说明：打开刚创建的箱子，拍照识别或手动添加物品。
- CTA：`记录箱内物品` / `Record an item`
- 目标：第一个箱子的公共地址；没有地址时回退到箱子列表。

CTA 按“关闭弹窗 → 执行导航”顺序工作；请求进行中会禁用 CTA 和关闭按钮，避免重复提交。

## 桌面端与移动端

桌面端：

- 弹窗在视口水平、垂直居中；
- 最大宽度受控，标题和步骤使用共享 typography token；
- Dashboard 顶部保留紧凑的手动“新手指南 / Getting started”入口。

移动端：

- 弹窗从底部出现，保留安全区内边距；
- 内容区域纵向滚动，局部隐藏横向溢出；
- CTA 使用整行宽度，适合单手操作；
- 390px 宽度下弹窗左右边界始终位于视口内，页面不出现横向滚动条。

两端共享相同的进度模型和文案键，仅布局断点不同。

## 全局多语言

### 语言来源与优先级

1. 首次加载读取 `localStorage.nomo-locale`；
2. 没有值或值非法时使用 `zh-CN`；
3. 用户在任意公开、认证或业务页面切换语言，立即更新全局 UI、`document.documentElement.lang` 和 localStorage；
4. 用户登录后，`LocaleProfileSync` 将当前偏好同步到 profile；同步失败不阻断界面切换，下次登录继续尝试。

登录状态不决定语言，也不会在登出时重置语言偏好。

### 文案约束

- `messages.ts` 中 `zh-CN` 和 `en-US` 叶子键集合必须一致；
- 每个叶子都必须是非空字符串；
- 当前语言缺键时回退到简体中文，并在开发环境输出缺键警告；
- UI 标题、按钮、placeholder、aria-label、toast、错误提示和加载状态均使用 `t()`；
- 用户输入、数据库内容、二维码内容和法律 Markdown 原文不进入 UI 字典。

## 前置条件保护

当用户在没有空间时尝试创建箱子，仍然直接跳转到空间创建流程，并说明“创建箱子前，需要先告诉 Nomo 它放在哪个空间”。这类业务保护不依赖引导弹窗，保证从导航、空状态和深链接进入时行为一致。
