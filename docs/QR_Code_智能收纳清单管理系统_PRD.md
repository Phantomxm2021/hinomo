# QR Code 智能收纳清单管理系统 PRD（第一阶段）

## 1. 产品定位

QR Code
智能收纳清单管理系统，通过二维码绑定实体容器（纸箱、收纳箱、文件盒、设备箱等），用户扫描二维码即可查看和维护箱内物品清单。

第一阶段目标：

> 实现「创建二维码 → 绑定容器 → 记录物品 → 扫码查看 →
> 增删改查」完整闭环。

暂不涉及： - NFC - AI自动识别 - RFID - 自动装箱 - 复杂库存管理

------------------------------------------------------------------------

# 2. 核心使用流程

## 用户流程

    注册账号

        ↓

# 4. 容器（Box）设计

每一个二维码代表一个唯一容器。

## Box字段

  字段          说明
  ------------- ------------
  id            系统唯一ID
  box_code      箱子编号
  name          箱子名称
  category      箱子类型
  location      存放位置
  description   备注
  cover_image   箱子图片
  qr_code_url   二维码地址
  owner_id      所属用户
  created_at    创建时间
  updated_at    更新时间

------------------------------------------------------------------------

## 示例

    箱子编号：
    BX-00001

    名称：
    冬季衣物

    位置：
    卧室衣柜上层

    备注：
    羽绒服、围巾、帽子

# 12. 二维码设计

二维码不要直接存储数据。

推荐：

二维码内容：

    https://domain.com/b/{box_id}

例如：

    https://box.app/b/BX00001

原因：

-   数据可以修改
-   支持迁移
-   支持权限控制
-   标签永久有效

不是二维码。
