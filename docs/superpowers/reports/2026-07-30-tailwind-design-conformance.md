## Chrome 实测

检查页面：登录、Dashboard、空间、箱子目录、箱子编辑、公开箱子、物品表单、搜索、打印、扫码入口。

检查视口：1440×900、1024×768、768×1024、390×844、360×800、320×568。

关键观测：

- 1440px 主内容宽度约 1200px，侧栏可见，移动导航隐藏，Dashboard 搜索右侧显示 46px 图标扫码按钮。
- 1024px 正确进入桌面布局；768px 仍使用移动布局。
- 390/360/320px 的底部导航均保留 12px 最小安全区内边距，中央扫码按钮可见，桌面扫码按钮隐藏。
- 登录页桌面为暖色双栏，移动端保持紧凑品牌表达；所有被检页面背景与标题颜色一致。
- 物品表单字段顺序为媒体、名称、分类、数量、描述；加减、取消、保存按钮实测高度均为 44px。
- 键盘 Tab 聚焦 Nomo 链接时，计算样式为 3px 实线品牌色轮廓、3px offset。
- 未接受或触发摄像头权限；Chrome 控制台未发现 error 或 warning。

## 已修复的验收问题

- 修复导航激活态被 muted 工具类覆盖。

- 修复编辑物品切换新增或另一物品时 RHF 默认值残留。
- 修复浏览器历史变化时 URL 搜索不同步。
- 修复切换打印箱子时旧二维码短暂匹配新元数据。
- 修复最终 CSS 清理后语义标题退化为正文大小。
