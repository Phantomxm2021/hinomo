# Nomo 布局与样式跟进审计

日期：2026-07-30

基准：`docs/superpowers/specs/2026-07-30-warm-family-ui-redesign-design.md`

## 审计方法

1. 逐条对照移动端/桌面端导航、页面标题、首页信息顺序、卡片结构、详情页固定操作区和认证页品牌规范。
2. 对每个发现先增加失败契约测试，再修改生产代码，最后用 Vitest、Playwright 和 Chrome 多视口复核。
3. Chrome 视口覆盖 1440、1024、768、390、360、320px，并检查计算样式、横向滚动和固定元素遮挡。

## 发现与修复

| 区域 | 原问题 | 修复 |
| --- | --- | --- |
| 全局标题 | `h1` 使用过大的旧字号和字距，桌面首页达到 72px。 | 收敛为移动 28px、桌面最高 36px，并同步视觉系统契约。 |
| 首页移动端 | 概览指标在移动端仍显示，打乱设计稿的信息顺序。 | 指标仅在 `lg` 桌面显示；移动端保持品牌入口 → 问候 → 搜索 → 空间 → 最近箱子。 |
| 首页品牌与空间卡片 | 移动端缺少品牌/账户入口；空间卡片缺少图标、柔和色块和备注。 | 增加移动品牌栏、账户入口、空间图标和可选描述；桌面侧栏保留 N 标识。 |
| 箱子列表 | 390px 下仍是一列；窄屏卡片操作会挤压。 | 移动默认两列，窄屏操作自动堆叠，320px 无横向溢出。 |
| 详情页/物品表单 | 移动新增按钮与表单保存按钮同时固定，真实点击会被拦截。 | 表单打开时隐藏移动新增按钮；保存栏固定在移动底部导航上方。 |
| 页面标题一致性 | 创建/编辑箱子、扫码、公开箱子详情页移动标题使用 30/36px。 | 统一移动 24px，桌面 36px。 |
| 认证页 | 登录标题实际为 30px，超出移动标题规范。 | 认证容器标题改为移动 24px、桌面 36px，并保留 Nomo 品牌标识。 |

## 验证证据

- Vitest：30 个测试文件、122 个测试通过。
- TypeScript：`tsc -b --noEmit` 通过。
- Oxlint：通过。
- Vite production build：通过；仅保留既有大 chunk 警告。
- Playwright E2E：9/9 通过，覆盖桌面、iPhone、pixel、权限和 1024px 断点。
- Chrome：1440/1024 显示桌面指标和侧栏；768/390/360/320 使用移动导航；320px `body.scrollWidth === innerWidth`；移动表单保存栏 `position: fixed` 且新增浮动按钮在表单打开时消失。

## 结论

本轮发现的布局、字号和移动交互遮挡问题已修复，并由自动化契约和真实浏览器复核覆盖。当前工作树仍在 `codex/tailwind-warm-family` 分支，尚未合并到主分支。

## 桌面稿一比一收敛（追加）

针对桌面参考图再次逐项比对后，首页继续做了减法：

- 搜索框内部移除“搜索”按钮，只保留输入框；扫码图标独立放在右侧。
- 侧栏移除参考图没有的“智能收纳清单”副标题，补齐底部用户区“林家的收纳空间 / 设置与退出”。
- 空间区和最近区移除参考图没有的橙色眉题。
- 空间卡只保留图标、空间名和箱子数量。
- 最近打开卡片移除箱号和物品数，只保留封面、箱名和位置。
- 指标卡补齐参考图中的三条辅助文案。

## 排版与设计语言收敛（追加）

本轮将参考稿中的文字层级从页面级零散工具类收敛为全局语义令牌：

- 系统字体栈统一为 SF Pro / 苹方 / 微软雅黑 / system-ui，并开启抗锯齿与可读性优化。
- 新增 `display`、`metric`、`page-title`、`section-title`、`card-title`、`body`、`meta` 和 `eyebrow` 语义层级。
- 首页问候使用唯一的 display 层级；管理页统一使用 page-title，不再分别维护移动/桌面字号。
- 眉题由橙色、超粗、宽字距改为参考稿的中性色、500 字重和克制字距。
- 侧栏导航由超粗激活态改为 700/500 的清晰层级；卡片标题、元数据、统计标签和浮层标题同步统一。
- 认证、空间、箱子、箱子详情、物品表单、搜索、扫码、打印和账户菜单均已迁移。

浏览器 1280px 计算样式抽查：

- 正文：16px / 24.8px，400。
- 眉题：14px / 20.3px，500，`#756A5E`。
- 普通页面标题：28.8px / 32.256px，800，`#30271E`。
- 输入文字：16px / 24.8px，400。

验证：Vitest 31 个文件 / 128 项通过；TypeScript、Oxlint、生产构建通过；Playwright desktop/iPhone/Pixel 9/9 通过。

## 首页卡片一比一收敛（追加）

根据设计稿的房间与最近箱子局部再次比对：

- 房间卡从统一 SVG 色块改为按空间名称匹配的生活化图形；客厅、卧室、书房和储藏室分别对应设计稿中的视觉标识，未知空间使用稳定的家庭图形兜底。
- 房间卡高度收敛为设计稿的紧凑比例，并补齐标题行右侧“管理空间 ›”入口。
- 最近箱子无封面状态改为三组稳定的低饱和棕、蓝灰、赭金色块与纸箱标识，不再绘制线框占位箱。
- 最近箱子封面从 `16:10` 改为约 `3.5:1` 的横向比例，匹配设计稿的浅封面、深内容分区。
- “管理空间 ›”与“查看全部 ›”统一使用次级文字颜色、元数据字号和中等字重。
