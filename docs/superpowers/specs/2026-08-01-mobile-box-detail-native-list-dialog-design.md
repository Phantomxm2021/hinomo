# 移动端箱子详情原生列表与物品弹窗设计

## 目标

将手机端箱子详情改为原生 App 风格：隐藏封面，使用连续物品列表，并以底部弹窗承载新增与编辑物品。桌面端保持现有封面、卡片列表和内嵌表单。

## 移动端详情

- 隐藏箱子封面。
- 保留编号、名称、可见性、更新时间和顶部导航。
- 物品采用 inset grouped list：左侧缩略图，中间名称与单行辅助信息，右侧数量和箭头。
- 点击整行进入编辑物品底部弹窗，不显示行内编辑/删除按钮。

## 物品弹窗

- 新增和编辑物品使用同一底部弹窗，具有遮罩、圆角顶部、安全区和可滚动正文。
- 弹窗标题区沿用现有表单标题；取消与保存操作继续可用。
- 编辑时在弹窗中提供删除操作，点击后继续使用现有二次确认对话框。
- 表单不再作为页面普通内容插入到物品列表之前。

## 桌面端

- 继续显示箱子封面。
- 继续使用现有卡片式物品布局、行内编辑/删除操作与内嵌表单。

## 验证

- 移动 cover 使用 `hidden lg:block`；桌面恢复显示。
- 移动物品行可编辑，行内编辑/删除控件在 `lg` 前隐藏。
- 新增/编辑表单以 `role="dialog"` 呈现，桌面保持静态内容。
- 删除仍需二次确认；创建、更新、上传失败和焦点恢复既有行为继续通过。
