# Nomo 入口与工作台集成设计

## 目标

消除所有用户可见的模板与占位页面，让访问根地址、登录和进入应用形成一条连续路径。现有空间、箱子、搜索、扫码、打印和公开查看功能保持不变，只补齐入口、工作台与统一视觉。

## 路由与会话行为

- `/` 是会话感知入口：认证状态加载时显示品牌化加载界面；未登录跳转 `/login`；已登录跳转 `/app`。
- `/app` 是真实工作台，不再渲染 `PlaceholderPage`。
- 未认证访问任何 `/app/*` 路径仍由 `RequireAuth` 跳转登录，并在登录成功后返回原目标。
- 未匹配的 `/app/*` 路由跳转回 `/app`，不展示占位页。
- `/b/:publicId` 保持独立公开/私有访问逻辑，不强制登录。

## 工作台

工作台复用现有 `listSpaces` 和 `listBoxes`，不增加数据库表、RPC 或迁移。页面展示：

- 空间总数、箱子总数、公开箱数量、私有箱数量。
- 创建箱子、扫码查看、搜索物品、批量打印四个快捷入口。
- 最近更新的三个箱子，包含编号、空间、位置和公开状态。
- 无箱子时显示明确的首次使用引导和“创建箱子”操作。
- 任一统计查询失败时保留其他可用内容，并显示可重试的中文错误提示。

## 视觉系统

采用温暖、清晰的家庭收纳风格：暖白背景、深墨色文字、紫色品牌强调、柔和卡片阴影和高对比操作按钮。桌面端保留侧边栏，移动端保留四项底部导航。

- 登录、注册和密码页面使用统一认证外壳、品牌说明与居中表单卡片。
- 应用工作台使用欢迎标题、统计卡片、快捷操作和最近箱子分区。
- 所有页面共用一致的按钮、输入框、卡片、焦点状态和安全区间距。
- 尊重 `prefers-color-scheme` 和 `prefers-reduced-motion`。
- 不引入图片素材、动画框架或新的 UI 依赖。

## 组件边界

- `RootEntry`：只负责读取认证状态并重定向。
- `DashboardPage`：负责读取现有空间/箱子数据并渲染聚合视图。
- `AuthLayout`：为四个认证页面提供统一品牌与布局容器；认证表单行为不变。
- `AppShell`：继续负责桌面侧边栏和移动导航，增加工作台入口并统一品牌区域。

各组件只依赖现有认证上下文、查询 API 和 React Router，不复制数据访问逻辑。

## 错误与加载状态

- 根入口等待认证初始化，不提前跳转以避免闪烁。
- 工作台使用骨架/状态文本表示加载；查询失败显示稳定中文提示。
- 工作台中的部分数据失败不会隐藏导航和快捷操作。
- 路由 fallback 使用重定向，避免用户再次看到占位内容。

## 测试与验收

- 单元测试先证明根入口按会话跳转、工作台聚合统计和空状态行为。
- 更新路由测试，证明代码中不再使用 `PlaceholderPage`。
- 全量运行 Vitest、TypeScript、lint 和生产构建。
- Playwright 覆盖未登录根入口、登录后工作台以及桌面/iPhone/Pixel 核心流程。
- 本地浏览器分别检查桌面与移动布局；不连接真实 Supabase 或 R2。

## 非目标

- 不增加营销落地页。
- 不修改数据库结构、RLS、RPC 或 R2 配置。
- 不增加账户设置、通知、图表或新的业务功能。
- 不重新设计公开箱数据权限。
