# 移动端箱子详情信息卡可见性设计

## 目标

在小于 `lg` 的视口隐藏箱子详情中的位置、备注与物品统计信息卡，使移动端详情更聚焦于封面、名称、状态和物品列表。

## 范围

- 隐藏的内容：位置路径、备注和“共 X 件 · Y 种物品”统计。
- 保留的内容：顶部导航、封面、箱子编号、名称、公开/私密状态、最近更新时间、物品清单和底部新增按钮。
- 桌面端继续显示完整详情信息，布局与内容不变。

## 实现与验证

- 为现有详情信息分组增加稳定测试标识。
- 使用移动端默认 `hidden` 与 `lg:contents` 恢复桌面网格内容，不改变数据或权限逻辑。
- 单元测试验证该组在移动端隐藏、桌面端恢复；全量测试确保无交互回归。
